# ADR-001: Single-tenant demo, no auth, RLS deferred

## Status
Accepted

## Context
NetPulse is a portfolio demo. There is no user authentication and no multi-tenancy.
Supabase Postgres is supported via `DATABASE_URL`, but the demo runs on SQLite by default.

## Decision
- No auth layer; all endpoints are open.
- RLS is NOT enabled in the initial migration. When auth is added, enable RLS
  on every table and replace the open policies with `auth.uid()`-scoped ones.
- Primary keys use UUID (string) for Supabase compatibility.
- All FKs use `ON DELETE CASCADE`.

## Consequences
- Do not deploy this as-is to a public internet-facing host without adding auth + RLS.
- Migrations must remain zero-downtime (expand/contract) once real users exist.
